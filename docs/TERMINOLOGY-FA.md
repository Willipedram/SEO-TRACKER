## تمایز غیرقابل ادغام

«رتبه ثبت‌شده توسط ردیاب» و «میانگین جایگاه سرچ کنسول» هرگز یک معیار نیستند.
اولی یک مشاهده دقیق از اجرای Rank Tracking است؛ دومی Average Position تجمیعی گوگل
برای Impressionهای منطبق است. عنوان، جدول، نمودار، گزارش CSV و نمای ترکیبی باید نام
منبع را حفظ کنند و هیچ‌کدام را صرفاً «رتبه» نمایش ندهند.

## اصطلاحات عمداً انگلیسی

`URL`، `API`، `OAuth 2.0`، `CSV`، نام موتور `Google`، نسخه‌ها و شناسه‌های داخلی به‌علت
معیاربودن یا خطر تغییر معنا انگلیسی می‌مانند. در اطراف آن‌ها جهت LTR ایزوله می‌شود؛
مقادیر خام مانند URL، ایمیل، IP، token و Git hash Tooltip تکراری دریافت نمی‌کنند.
